# 我的机器人 🤖

「我的机器人」是你管理机器人本体的地方：新增、查看状态、进详情页管插件、翻消息记录和日志。

这页按你实际的操作顺序讲：先怎么加，加完在列表里看到什么，点进去之后五个 Tab 分别能干什么。

## 1. 添加机器人：两步向导

点右上角「添加机器人」，向导分两步。

### 第 1 步：选平台

| 平台 | 说明 |
|---|---|
| `qq_official` | QQ 官方开放平台机器人，支持 Webhook 回调与 WebSocket 网关两种连接方式 |
| `qq_onebot` | 通过 NapCat / go-cqhttp 等实现端接入的 OneBot 11，只支持反向 WebSocket |

选哪个见 [接入方式总览](/platforms/overview)。

### 第 2 步：填名称与平台配置，并选连接方式

| 字段 | 说明 |
|---|---|
| 名称 | 只用于你在控制台里区分机器人，不影响机器人本身 |
| 平台配置 | 随第 1 步的平台变化：`qq_official` 要 `AppID` / `AppSecret` / 环境；`qq_onebot` 无需额外凭据 |
| 连接方式 | `qq_official` 可选 WebSocket 网关或 Webhook 回调；`qq_onebot` 固定为反向 WebSocket |

提交后机器人**立即上线，不需要重启服务**。如果你选的是 Webhook 或 OneBot，创建完成后页面上会给出需要回填到平台 / 实现端的地址，照着填即可。

::: tip 建之前先确认额度
机器人数受套餐限制。额度不够时添加会被拒绝，需要先升级套餐或删掉不用的机器人，见 [订阅 · 卡密 · 充值](/console/billing)。
:::

## 2. 机器人列表

列表里每行是一台机器人，你主要关注这几列：

| 列 | 看什么 |
|---|---|
| 名称 | 你创建时起的名字 |
| 适配器 | `qq_official` 或 `qq_onebot` |
| 连接方式 | WebSocket 网关 / Webhook 回调 / 反向 WebSocket |
| 状态 | 在线还是离线 |
| 操作 | 进入详情、删除等 |

**判断机器人是否在线**，直接看列表的状态列即可；进详情页的「设置」Tab 也能看到同样的状态，以及更细的信息。

## 3. 机器人详情页的五个 Tab

点进一台机器人，顶部有五个 Tab。

### 插件

这台机器人当前装了哪些插件，以及每项的操作：

- **启用 / 停用**：单独控制某个插件在这台机器人上跑不跑
- **优先级**：调整插件的执行顺序，值越小越先执行
- **三个拦截开关**：控制这个插件的拦截能力在这台机器人上生不生效
  - `Incoming 拦截`：消息进来时先过一遍这个插件（可以改写甚至拦下消息）
  - `Outgoing 拦截`：机器人要发出去的消息先过一遍这个插件（可以改写或阻止发送）
  - `AfterSend 回调`：消息发出后通知这个插件（用来记录发送结果、做后续动作）
- **进入插件面板**：打开插件自带的 Web 面板，做这个插件在这台机器人上的配置

注意插件配置是**按机器人维度**存的：同一插件装到两台机器人上，是两份独立配置。

### 事件转发

**只有 Webhook 模式接入的机器人才能看到这个 Tab。** 用它查看和配置事件往哪里转发。

如果你用的是 WebSocket 网关或 OneBot，看不到这个 Tab 是正常的，说明该模式不需要它。

### 数据

这台机器人的运行数据：

- 消息记录：群里收发的消息流水
- 插件数据：插件自己存下来的数据

排障时「群里到底有没有收到消息」在这里最直观。

### 日志

**这台机器人自己的运行日志**，不用登服务器、不用翻整个服务的日志。连接断开、事件处理报错这类问题都在这里看。

### 设置

机器人的身份与状态信息：

| 显示项 | 说明 |
|---|---|
| UUID | 这台机器人在控制台里的唯一标识 |
| 适配器 | `qq_official` 或 `qq_onebot` |
| 连接方式 | 当前用的连接方式 |
| 状态 | 在线 / 离线 |
| 支持能力列表 | 这台机器人当前支持的能力，写插件调用能力码时可以对照 |

机器人详情页的排障入口基本就是这三个：**设置看状态、日志看原因、数据验证消息有没有进来**。

## 4. 让机器人进群

机器人本身不会自动进群，需要你手动把它拉进去：

- **QQ 官方机器人**：在 QQ 开放平台把机器人配置好之后，用群管理操作把它拉进目标群。默认它只在被 @ 时收到消息；要收全量消息需要「群全量消息」授权，见 [QQ 官方：WebSocket 网关](/platforms/qq-official)。
- **OneBot 11**：机器人就是你自己登录的那个 QQ 号，用这个号正常加群即可，见 [QQ OneBot 11](/platforms/qq-onebot)。

拉进群之后，在群里发条消息，回到详情页「数据」Tab 确认消息进来了。

## 5. 常见问题

### 症状：新建的机器人一直离线

- **原因**：凭据填错、实现端没连上，或端口 / 地址填错。
- **处理方式**：按适配器分别排查——QQ 官方看 [WebSocket 网关](/platforms/qq-official) 的排错清单，OneBot 看 [QQ OneBot 11](/platforms/qq-onebot) 的排错清单。

### 症状：机器人删掉了，但额度没释放

- **原因**：页面缓存未刷新。
- **处理方式**：刷新页面再看订阅中心的额度显示。

### 症状：装了插件但机器人没反应

- **原因**：插件只是装上了，没有**启用**。
- **处理方式**：到「插件」Tab 确认该插件处于启用状态，且处于启用优先级链里。
