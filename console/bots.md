# 机器人管理

> **你会学到**：怎么创建机器人、填凭证、装插件、配置、监控。

## 创建机器人

1. 进入机器人管理，点「创建机器人」。
2. **选择平台**：从[支持的平台](../platforms/supported)里选一个（QQ 官方、Telegram 等）。
3. **填写凭证**：按平台要求填应用 ID、Token、Secret 等。
4. **配置连接**：
   - Webhook 类：把生成的回调地址填到平台后台。
   - WebSocket / 轮询类：确认连接信息无误。
5. **命名保存**。

::: warning 配额限制
可创建的机器人数量由你的[订阅套餐](./subscriptions)决定。配额用完需升级套餐或删除旧机器人。
:::

## 机器人列表

每条机器人显示：

- 名称、平台、状态（运行中 / 已停用 / 异常）
- 绑定的插件数量
- 创建时间

支持启停、编辑、删除。

## 配置机器人

点进某个机器人，可以配置：

### 适配器设置

每个平台的机器人有一组**适配器行为设置**，例如 QQ 官方：

| 设置 | 作用 |
|------|------|
| 全量消息当作普通群消息 | 群里非 @消息也当作普通消息处理 |
| 忽略其他机器人发的消息 | 过滤掉其他 bot 的消息 |
| 忽略只 @其他机器人的消息 | 减少无关处理 |
| 忽略 @全体成员的消息 | 不响应 @全体 |
| 事件去重 | 防止重复处理 |

::: tip 全量消息
开启「全量消息当作普通群消息」后，你的机器人能收到群里所有消息（不只 @它的），更多插件会触发。按需开启。
:::

### 已安装插件

查看这个机器人装了哪些插件，每个插件可：

- 启用 / 停用
- 配置参数（来自插件的 `setting.json`）
- 设置优先级、拦截器开关
- 卸载

### 插件 WebUI

装了 WebUI 的插件，在机器人配置页内嵌展示管理界面（如签到排行、商城订单）。

## 监控

查看机器人运行状态、最近事件、插件执行情况。异常会在列表标红。
