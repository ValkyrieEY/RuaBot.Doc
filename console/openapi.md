# Open API

> **你会学到**：用 Open API 把 V3 的能力接入你自己的系统。

## 什么是 Open API

除了 Web 控制台，V3 还提供 **HTTP API**，凭 **API Key** 调用，方便你做二次集成：

- 在自己的网站 / App 里查询机器人状态。
- 用脚本批量管理。
- 和其他系统对接。

## 创建 API Key

1. 进入控制台的 Open API 页面。
2. 点「创建 API Key」。
3. 给 Key 起个名字（标记用途）。
4. 保存生成的 Key。

::: warning 妥善保管
API Key 等同于你的账户凭证，泄露后别人能用它操作你的账户。创建后只显示一次，记得保存；不用了及时删除。
:::

## 调用方式

所有 API 请求：

- 带上 `Authorization: Bearer <你的API Key>` 请求头。
- 按接口文档传参。

## API 文档

Open API 页面提供**交互式接口文档**，可：

- 查看所有可用接口、参数、返回格式。
- 在页面上直接试调（填参数、发请求、看结果）。
- 复制调用示例。

常见接口类型：

| 类别 | 示例 |
|------|------|
| 机器人管理 | 列出 / 创建 / 启停机器人 |
| 插件管理 | 列出已装插件、安装 / 卸载 |
| 消息发送 | 主动给指定目标发消息 |
| 订阅 / 账户 | 查询余额、订阅状态 |

::: tip 先看交互式文档
具体接口路径、参数以控制台里的交互式文档为准（它会随版本更新）。本页只做概念介绍。
:::
