# 插件中心

> **你会学到**：怎么找插件、购买、安装到机器人、配置。

## 浏览插件

插件中心展示所有已上架的插件，支持：

- 按分类筛选（游戏 / 系统 / 工具 / 娱乐 / 社交 / AI 等）。
- 搜索关键词。
- 按热门 / 最新排序。

每个插件卡片显示：名称、作者、简介、价格、分类。

## 购买 / 安装

| 类型 | 流程 |
|------|------|
| **免费插件** | 直接点「安装」即可 |
| **付费插件** | 点「购买」→ 余额支付 → 自动安装 |

::: tip 套餐含插件
某些订阅套餐已包含指定插件（见[我的订阅](./subscriptions)），这些插件无需单独购买。
:::

## 绑定到机器人

安装插件后，需要把它**绑定到具体的机器人**才会运行：

1. 进入某个机器人的「已安装插件」。
2. 启用要用的插件。
3. 配置插件参数（如有 `setting.json`）。

一个插件可以绑到多个机器人，各自独立配置、独立运行。

## 配置插件

插件的配置项由开发者通过 `setting.json` 定义（见[插件开发 · 配置项](../plugin-dev/settings)）。常见配置：

- 触发关键词
- 管理员列表
- 运行模式
- API 密钥等

改完保存即生效（约 30 秒缓存延迟）。

## 插件管理

| 操作 | 说明 |
|------|------|
| 启用 / 停用 | 临时开关，不卸载 |
| 卸载 | 从机器人移除 |
| 升级 | 插件有新版本时提示升级 |
| 优先级 | 多个插件时的执行顺序 |
| 拦截器开关 | 是否启用该插件的出站拦截 |
