# 控制台总览 🔧

控制台是你日常使用 Xiaoyi_QQ_V4 的主界面：建机器人、装插件、看日志、查账单、生成 API Key 都在这里完成，不用登服务器。

这页给你一张地图——六个模块各管什么，以及从零到「机器人在群里回话」的最短路径。

## 1. 六个模块

登录后左侧是导航，一共六块：

| 模块 | 管什么 | 什么时候会用到 |
|---|---|---|
| 仪表盘 | 概览：机器人数量、在线情况、服务器负载等 | 每天进来先看一眼 |
| 我的机器人 | 添加 / 查看机器人，进详情页管插件、看数据与日志 | 接入机器人、排障 |
| 插件市场 | 浏览插件、装到某台机器人、启停与调优先级 | 给机器人加功能 |
| 订阅中心 | 套餐、余额、卡密兑换、充值 | 额度不够、到期续费 |
| 用户中心 | 账号资料、通知、开放 API 的 Key | 生成 API Key、看账单通知 |
| 开放 API | 用程序调用框架能力 | 做二次开发、对接自有系统 |

「开放 API」这块的具体接口清单见 [开放 API](/console/openapi)。

## 2. 第一次上手：五步

### 第 1 步：打开控制台并登录

用服务商给你的访问地址打开页面（默认是服务器的 `8080` 端口，通常已经套好域名和 HTTPS）。首次使用需要注册账号。

### 第 2 步：确认订阅状态

账号注册好之后，先去「订阅中心」看当前套餐。**套餐决定你能建几台机器人、装几个插件**——额度用满是新手最常见的卡点。

如果服务商给你的是卡密，在这一步兑换，见 [订阅 · 卡密 · 充值](/console/billing)。

### 第 3 步：添加第一台机器人

进「我的机器人」→「添加机器人」，跟着两步向导走。你需要先准备好机器人的凭据（QQ 官方的 `AppID` / `AppSecret`，或一个跑起来的 OneBot 实现端），具体见 [接入方式总览](/platforms/overview)。

创建后机器人**立即上线**，不需要重启服务。

### 第 4 步：装插件

进「插件市场」，挑一个插件装到刚建的机器人上，然后启用。装完可以打开插件自带的 Web 面板做配置，见 [插件市场与安装](/console/plugins)。

### 第 5 步：验证

到机器人详情页看「日志」Tab 有没有正常运行输出；在群里发条消息，看「数据」Tab 里有没有消息记录。

到这一步，一个能用的机器人就跑起来了。后面的「用户中心 → 开放 API」只有在你需要用程序调用时才要配。

## 3. 关于注册限制

服务商可以开启注册限制。如果你看到的是受限的注册页，通常会遇到这些要求：

| 你会看到 | 说明 |
|---|---|
| 注册需要填 QQ 号 | 用真实可联系的 QQ 号，后续找服务商处理问题时会用到 |
| 可能需要邮箱验证 | 按页面提示去邮箱点验证链接 |

如果注册被拒绝、或者填完提示不允许注册，说明服务商当前关闭了自助注册，需要直接联系服务商开通账号。

::: warning 找服务商，不要自己想办法绕
注册限制、额度、授权这些都由服务商控制，页面上没有开关。遇到问题请联系服务商，不要尝试改配置或数据库。
:::

## 4. 几个通用约定

- 页面上的操作**即时生效**，不需要重启服务；只有换端口、换数据库连接这类部署级配置才需要重启
- 机器人的运行日志在它自己的详情页里，不用去服务器上翻
- 插件的数据和配置是**按机器人维度**存的——同一插件装到两台机器人上，是两份独立配置
