# 控制台总览

> **你会学到**：用户控制台能做什么、各功能模块概览。

用户控制台是**租户（最终用户）**使用的自助界面，登录入口在控制台登录页。在这里管理你自己的机器人、插件、订阅。

## 核心模块

| 模块 | 作用 |
|------|------|
| [机器人管理](./bots) | 创建、配置、监控机器人 |
| [插件中心](./plugins) | 浏览、购买、安装插件 |
| [我的订阅](./subscriptions) | 查看订阅、续费 |
| [账户与充值](./account) | 余额、充值、账单 |
| [Open API](./openapi) | 管理 API Key、二次集成 |

## 上手流程

新用户首次使用，典型路径：

1. **充值 / 购买订阅**：在[账户与充值](./account)充值余额，或在[我的订阅](./subscriptions)购买套餐。
2. **创建机器人**：在[机器人管理](./bots)创建机器人，选择平台、填凭证。
3. **安装插件**：在[插件中心](./plugins)浏览并安装需要的插件，绑定到机器人。
4. **配置插件**：在机器人设置里配置各插件的参数。
5. **启动机器人**：机器人开始接收消息、响应。

## 资源配额

你的资源（机器人数量、插件数量、可用平台）由**订阅套餐**决定：

- 套餐配额用完，无法新建机器人 / 装插件。
- 订阅过期，资源降级（停用，不删数据），续费恢复。
- 升级套餐立即获得更高配额。

详见[我的订阅](./subscriptions)。
