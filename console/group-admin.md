# 群管使用指南

群管是随框架提供的最完整的一个插件：从内容拦截、成员处置到入群管理、问答、统计、签到、定时播报都能覆盖。装到机器人上之后，大部分功能都在**插件面板**里配，常用操作也可以在群里用指令完成。

::: tip 面板在哪
控制台 → 我的机器人 → 选中机器人 → 「插件」Tab → 群里管理 → 进入插件面板。
面板是**按机器人**隔离的：同一插件装在两台机器人上，配置互不影响。
:::

## 权限模型（先搞清这个）

群管的所有管理指令都按下面的顺序判权限：

```text
主人 > 副主 > 群主 / 群管理员 > 普通成员
```

| 角色 | 说明 |
| --- | --- |
| **主人** | 在插件面板里配置的账号列表。**留空时，该群的群主自动视为主人**，所以开箱即用 |
| **副主** | 主人之外再授权若干人，可执行管理指令（只有主人能增删副主） |
| 群主 / 群管理员 | 由平台上报的群内角色，自动放行 |
| 普通成员 | 只能使用面向成员的指令（签到、我的统计、问答等） |

## 一、内容检测与处罚

**检测项**（每一项独立开关 + 独立处置）：

| 检测 | 说明 |
| --- | --- |
| 违禁词 | 分群词库 + 全局词库两级 |
| 链接 / 卡片 / 转发消息 | 分别拦截 |
| 手机号 | 自动识别手机号格式 |
| QQ 号 | 自动识别纯数字账号 |
| 刷屏 | 时间窗口 + 条数阈值判定 |
| **全撤模式** | 非白名单、非管理员的消息**一律撤回**（最严格的一档） |

**处置档位**：`警告` / `撤回` / `禁言` / `踢出`（可带拉黑），每项检测可单独指定。

**处罚升级**：可以设置「警告 N 次后自动禁言」，也可以设置**阶梯禁言**（第 1/2/3 次违规分别禁言不同时长，超出次数沿用最后一档）。所有违规都会记进**违规记录**，可按人查看与清除。

命中处罚时，如果开了「回执提醒」，群里会播报处理结果。

## 二、入群验证与审批

**入群验证**：新人进群先答题（算术题，QQ 官方平台会带按钮选项），验证期内发言会被撤回；答错按阶梯延长冷却。可配置：

- 验证有效期（默认 5 分钟，答错后自动翻倍，有上限）
- 验证期间是否禁言
- **免验证名单**：名单内的人进群直接放行

**入群审批**：有人申请入群时，把申请播报到群里（QQ 官方平台带「同意 / 拒绝」按钮），也可以：

- 用指令审批：`同意 <编号>` / `拒绝 <编号> [原因]`
- 设置审批策略：手动 / 自动通过 / 自动拒绝 / 自动拉黑
- **关键词审批**：申请留言命中关键词时自动通过

## 三、成员处置

- **禁言**：`禁言 @成员 [分钟]`、`禁言 <用户ID> [分钟]`，也可以**引用某人的消息**后直接发 `禁言 10`
- **永久禁言**：受平台单次禁言上限约束，本插件用「平台上限 + 到期自动续期」实现
- **踢出**：`踢出 @成员 [拉黑]`
- 另有**针对撤回名单**（名单内成员的消息全部自动撤回）、**撤回最近 N 条**、**禁言记录**与**单人禁言状态查询**

## 四、黑白名单

| 名单 | 作用 |
| --- | --- |
| **黑名单** | 该成员的消息被撤回，其指令被忽略 |
| **白名单** | 该成员**免于本插件的全部处罚与拦截**（信任名单） |

各自都有「本群」与「全局」两份。同时出现在两个名单里时，**白名单优先**。

## 五、授权系统（把群管当服务卖时用）

默认**不启用**，不影响任何群。启用「授权模式」后，**未授权的群不会执行拦截、也不响应群管指令**（主人和副主仍然可用，方便现场处理）。

- 给当前群或指定群授权：`30 天` / `90 天` / `永久`，可以带备注
- 随时查询某群剩余天数、清除单个或全部授权
- **到期提示**：快到期时（默认剩余 3 天内）在群里提醒一次，每天最多一次

## 六、问答 / 统计 / 签到 / 定时

| 系统 | 能做什么 |
| --- | --- |
| **问答** | 精准问答（整词相等）与模糊问答（包含即命中），各有「本群」与「全局」两套；`精准问你好答你好呀` 这样增删查 |
| **统计** | 发言日榜 / 周榜 / 月榜，我的发言与我的统计，进群 / 退群统计；可开关「榜单记录」与「榜单查询权限」 |
| **签到** | `签到` 得随机积分（默认 5~15），连续签到有额外奖励；有日榜与总榜；货币名称、奖励区间、连续签到目标都可配 |
| **定时** | `添加定时 21:30#晚上好`，到点自动往群里播报；支持开关与删除 |

::: warning 统计与榜单默认是关的
「榜单记录」默认关闭（避免一装就产生持续增长的存储）。需要时在面板或群里发「开启榜单记录」。
:::

::: warning 定时播报依赖平台授权
定时消息属于**主动消息**，在没授权的群会发送失败（属平台限制，不是插件故障）。失败只记审计，不会刷屏。
:::

## 七、入群 / 退群提示

可以分别设置**入群提示**与**退群提示**的文案并单独开关，群里有人进出时自动播报。

::: tip 和「入群欢迎」插件的关系
群管自带的提示更完整（支持退群提示）；独立的「入群欢迎」插件保留给只需要欢迎语的场景。两者可以同时装，不冲突。
:::

## 八、常用指令速查

在群里 @ 机器人发「**群管菜单**」，会按分组列出全部指令（开关设置 / 词库管理 / 处罚管理 / 禁言管理 / 入群管理 / 刷屏设置 / 问答系统 / 统计系统 / 签到系统 / 定时系统 / 黑白名单 / 授权系统 / 主人系统 / 运维指令）。

发分组名（例如「处罚管理」）可以只看该组的指令，不用记完整的指令表。

**所有面向用户可见的文案都可以改**：面板「回复模板」里有 100 多条模板，支持 Markdown 与纯文本两版，改完立即生效。
