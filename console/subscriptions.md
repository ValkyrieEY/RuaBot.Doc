# 我的订阅

> **你会学到**：查看订阅状态、购买 / 续订套餐、用卡密兑换。

## 查看订阅

显示你当前的订阅：

- 套餐名称、计费模式（月 / 年 / 永久）
- 到期时间、剩余天数
- 资源配额（机器人数、插件数）及已用量
- 套餐包含的插件、可用平台

## 购买 / 升级套餐

在套餐列表选择适合的套餐购买：

- 用[账户余额](./account)支付。
- 升级套餐：补差价升级到更高套餐，立即获得更高配额。
- 购买后订阅立即生效。

::: tip 永久套餐
永久套餐一次购买长期有效，适合长期使用者。月 / 年付则需到期前续费。
:::

## 续费

订阅快到期时会提醒。续费可：

- 手动续费：在「我的订阅」里点续费。
- 续费后到期时间顺延。

::: warning 过期降级
订阅过期后，资源会**降级**（机器人停用、插件停用），但**数据不删除**。续费后立即恢复，历史配置和插件数据都在。
:::

## 卡密兑换

有卡密可在「卡密兑换」里使用：

| 卡密类型 | 兑换 |
|---------|------|
| 套餐卡 | 获得一个订阅套餐 |
| 余额卡 | 充值到账户余额 |
| 插件卡 | 获得某个付费插件 |

输入卡密兑换即可。

## 配额说明

你的套餐决定：

- 可创建的**机器人数量**上限。
- 可安装的**插件数量**上限（部分套餐按"每机器人"或"共享"计算）。
- 可用的**平台适配器**（高级套餐支持更多平台）。
- **包含的插件**（套餐内免费使用）。

配额用完需升级套餐，或停用 / 删除不需要的资源。
