# 账户与充值

> **你会学到**：管理账户余额、充值、查看账单。

## 账户余额

余额用于：

- 购买[订阅套餐](./subscriptions)
- 购买[付费插件](./plugins)
- 续费

账户页显示当前余额、冻结金额。

## 充值

支持在线充值：

1. 选择预设档位，或输入自定义金额。
2. 选择支付方式（彩虹易支付，支持支付宝 / 微信等）。
3. 完成支付，余额实时到账。

::: tip 充值 vs 直接购买
充值是把钱存进账户余额，之后用余额买套餐 / 插件。也可以在购买时直接跳支付，效果一样。充值的好处是余额可分多次使用。
:::

## 账单 / 流水

查看所有资金变动记录：

| 类型 | 说明 |
|------|------|
| 充值 | 在线充值入账 |
| 购买套餐 | 扣费买订阅 |
| 购买插件 | 扣费买插件 |
| 续费 | 扣费续订 |
| 卡密兑换 | 卡密充值入账 |
| 管理员调整 | 平台手动调整（赠送 / 扣减） |

每条记录有时间、金额、类型、关联订单，可对账。
