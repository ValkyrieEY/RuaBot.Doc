插件市场与安装 🧩 ​

插件是给机器人加功能的唯一方式。控制台里的「插件市场」负责浏览和安装，「我的机器人 → 插件 Tab」负责启停和调优先级。

这页把「看到一个插件」到「它真的在机器人上跑起来」这条链路讲完，顺带说清配额限制。

1. 浏览市场 ​

进「插件市场」，列表里每个插件会显示：

显示项说明
插件名称与简介这个插件是干什么的
已安装机器人数有多少台机器人装了它，可以当作热度参考
版本当前上架的版本

点任意一项进入插件详情页，能看到更完整的介绍、支持的平台以及安装入口。

截图占位

截插件市场列表页，重点露出「已安装机器人数」这一列的数值。

2. 把插件装到机器人上 ​

在插件详情页点安装，选择要装到哪一台机器人。注意插件是按机器人安装的：

  • 你有三台机器人，想都装上同一个插件，就要装三次
  • 每台机器人上的同名插件是独立的一份，配置互不影响

装完之后：

  1. 回到「我的机器人」，进目标机器人详情页
  2. 打开「插件」Tab，确认新插件出现在列表里
  3. 处于启用状态

装上了不等于在跑

安装只是把插件放到这台机器人上。没启用的话它不会响应任何事件。机器人「没反应」时，先确认这一步。

3. 启用、停用与优先级 ​

在机器人详情页的「插件」Tab 可以：

操作作用
启用 / 停用单独控制这个插件在这台机器人上跑不跑，不影响其他机器人
调整优先级决定插件的执行顺序，值越小越先执行
三个拦截开关Incoming 拦截（消息进来先过这个插件）/ Outgoing 拦截（发出去的消息先过一遍）/ AfterSend 回调（发出后通知插件），机制见 拦截器
进入插件面板打开插件自带的 Web 面板做配置

优先级在多个插件都会处理同一条消息时才需要动：谁先拿到消息、谁能拦截后续处理，都由优先级决定。

4. 打开插件自带的 Web 面板 ​

不少插件自带一个独立的 Web 面板，用来做它自己的配置——比如填 API 地址、选触发词、开关子功能。

  • 入口在机器人详情页的「插件」Tab，点「进入插件面板」
  • 面板是插件自带的独立页面，长什么样由插件作者决定
  • 面板里的配置存在机器人维度：同一插件装在两台机器人上，两边的面板配置是分开的

插件作者想给自己的插件加面板，见 插件 Web 面板。

5. 配额 ​

新建机器人与安装插件都受套餐配额限制，新账号的免费额度是：

项目免费额度
机器人位1 个
插件位5 个

插件位是按「装了多少份」算的——同一个插件装到三台机器人上，占三个插件位。

超出额度时再装插件会失败，并提示 plugin_quota_exceeded。两种处理方式：

  1. 卸载不用的插件：在对应机器人的「插件」Tab 里卸载，释放插件位
  2. 升级套餐：套餐决定机器人位与插件位，见 订阅 · 卡密 · 充值

卸载前先想清楚

卸载会一并移除这个插件在这台机器人上的配置与数据。只是暂时不用的话，停用就够了。

6. 常见问题 ​

症状：安装时报 plugin_quota_exceeded ​

  • 原因：插件位用满了。
  • 处理方式：卸载不用的插件，或升级套餐。

症状：插件装了也启用了，但机器人不响应 ​

  • 原因：插件自身没配置（比如缺 API Key、缺触发词），或者被更高优先级的插件拦截了。
  • 处理方式：先打开插件面板补全配置；再检查是否有其他插件拦截了消息，必要时调整优先级顺序。

症状：插件面板打不开 ​

  • 原因：这个插件本身没有提供 Web 面板。
  • 处理方式：面板是可选能力，没有面板的插件按插件详情页里的说明配置即可。

症状：换了台机器人，插件配置是空的 ​

  • 原因：这是预期行为，插件配置按机器人维度存储。
  • 处理方式：在新机器人的插件面板里重新配置一遍。
