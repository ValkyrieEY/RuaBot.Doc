内置插件一览 ​

这些插件随框架提供，在控制台「插件市场」里可以直接装到你的机器人上。每一条都标了是否需要平台额外开权限——需要开权限的功能，没开通时的表现是"操作失败"，而不是静默无效。

以市场为准

插件会持续增加和更新，本页只是导读；某个插件是否可用、当前版本、需要什么权限，以「插件市场」里实际列出的为准。

社群管理 ​

群管 ​

功能最全的一个，装到群管类机器人上基本够用：

功能覆盖 12 个子系统：内容检测与处罚（违禁词 / 链接 / 卡片 / 转发 / 手机号 / QQ 号 / 刷屏 / 全撤模式）、 处罚升级（警告、阶梯禁言、违规记录）、入群验证与审批、成员处置（禁言 / 踢出 / 针对撤回）、黑白名单、 授权系统（按群授权 30 天 / 90 天 / 永久 + 到期提醒）、问答、发言统计、签到、定时播报、入群退群提示、 主人与副主。完整说明见 群管使用指南。

  • 有插件面板：词库、名单、功能开关、入群策略、回复模板、审计日志都在网页上配。
  • 按钮与 Markdown：QQ 官方平台下，入群审批播报会带可点击的按钮；其它平台用文字指令（如回复「同意 1」）。
  • 需要平台权限：禁言、踢人、查群成员、入群审批这些依赖平台接口，机器人还需是群管理员。见 平台能力码。
  • 默认值：授权模式默认关闭、榜单记录默认关闭、签到默认开启——都不影响既有群。

违禁词 ​

轻量版内容拦截：命中违禁词自动撤回，可选自动禁言，支持全局词库与分群词库。不需要面板，词库用群内指令维护。

针对撤回 ​

把指定成员加入「针对名单」，之后他在群里发的消息会被自动撤回。适合处理屡教不改的成员。

入群欢迎 ​

群成员进群时发送欢迎语，支持黑白名单、每日次数上限与文案模板。

消息与互动 ​

消息发送 ​

网页直接给群发消息的控制台：左侧群列表、右侧聊天窗口，不用加插件、不用写指令。

能力说明
群列表机器人收到过消息的群会自动出现在列表里，不需要手工配置
聊天窗口显示该群最近的消息，收到和发出的都显示；从这里发出的消息会立刻出现在气泡流里
被动消息用该群近 5 分钟内的消息作为回复凭证发送，不占用主动消息配额
主动消息不需要回复凭证，但需要平台授权；没权限时面板会直接拒绝并提示改用被动消息
消息类型文本、Markdown、图片（填图片链接）、图文混合

几个使用要点：

  • Markdown 只在 QQ 官方平台渲染，其它平台会按纯文本发出（面板上有提示）。
  • 图片只支持 URL，不是上传文件；把图片链接填进去即可。
  • 「被动消息」为什么要求近 5 分钟：平台对引用原消息的被动回复豁免主动频控，超过 5 分钟凭证就失效了。这时改用「主动消息」。
  • 面板显示的聊天记录会保留：每个群最近 50 条落库，服务重启后仍然能看到（更早的按条数自动滚动淘汰）。

自定义 API ​

不用写代码，把「一段指令」接到「任意外部 HTTP 接口」上，并把返回结果按模板变成文本或图片回发。支持多步链式调用（前一个接口的结果喂给后一个）、变量替换与条件分支。有插件面板，配置在网页里完成。

关键词回复 ​

最简单的自动回复：群里出现某个关键词就回一段固定文本。有插件面板。

多平台点歌 ​

支持网易云、QQ 音乐、汽水、酷我四个平台：搜索 → 按钮选歌 → 歌词 / 卡片 / 下载链接。

聚合视频解析 ​

群里有人发抖音 / 快手 / B 站的分享链接时，机器人自动把它解析成无水印的直链回发出来——视频会直接以视频消息发出，图集会逐张或合并发出，不用点开原链接。

能力说明
支持平台抖音（v.douyin.com）、快手（v.kuaishou.com）、B 站（b23.tv），每个平台可单独开关
图集处理多图内容逐张发送；QQ 官方平台下可开启「图集 Markdown 合并发送」，把整组图塞进一条消息，绕开被动回复的条数限制
发送效果先回一条含封面、标题、作者、简介的说明，再发视频本体 / 图集图片，内容以解析服务返回的为准
失败兜底网络异常回「API请求失败，请检查网络」；接口返回失败时回它给的提示文案，不会静默失败

需要先配置 API 密钥：这个插件走的是第三方聚合解析服务（api-v2.yuafeng.cn），需要去该服务申请一个密钥，填到插件设置里才能用。没有密钥时插件不工作。

  • 有配置表单：在机器人详情页 → 插件 Tab → 该插件的「配置」里填密钥、开关平台、调整图集发送参数。
  • 不需要平台额外开权限：解析本身是纯 HTTP 调用；只有发送媒体时依赖平台能力（见 平台能力码）。

群禁言 ​

独立的小工具：群内发「禁言 @某人 分钟」或「解禁 @某人」。功能和群管插件里的禁言重叠，二选一即可。

群信息与工具 ​

群状态 / 群信息 ​

查询群的名称、成员数、机器人在群里的角色、是否可主动推送消息、入群时间等信息。排错时很有用：怀疑权限问题时，先看一眼机器人当前的群内身份与授权状态。

我的 ID ​

回复发送者自己的标识（群里会附带群标识）。做接口联调、填「针对名单」时取标识用得上。

全量申请 ​

生成「群全量消息授权」的深链，群主在 QQ 里点开即可授权。

不授权会怎样

QQ 官方平台默认只把 @ 机器人的消息推给它。没做全量授权时，群管、关键词回复这类需要看全部消息的插件都不会触发。

速度测试 ​

回复框架收到消息到发出回复的耗时，用来判断"慢"是慢在网络还是慢在插件。
