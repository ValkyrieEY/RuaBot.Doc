群管使用指南 ​

群管是随框架提供的最完整的一个插件：从内容拦截、成员处置到入群管理、问答、统计、签到、定时播报都能覆盖。装到机器人上之后，大部分功能都在插件面板里配，常用操作也可以在群里用指令完成。

面板在哪

控制台 → 我的机器人 → 选中机器人 → 「插件」Tab → 群里管理 → 进入插件面板。 面板是按机器人隔离的：同一插件装在两台机器人上，配置互不影响。

权限模型（先搞清这个） ​

群管的所有管理指令都按下面的顺序判权限：

text
主人 > 副主 > 群主 / 群管理员 > 普通成员
角色说明
主人在插件面板里配置的账号列表。留空时，该群的群主自动视为主人，所以开箱即用
副主主人之外再授权若干人，可执行管理指令（只有主人能增删副主）
群主 / 群管理员由平台上报的群内角色，自动放行
普通成员只能使用面向成员的指令（签到、我的统计、问答等）

一、内容检测与处罚 ​

检测项（每一项独立开关 + 独立处置）：

检测说明
违禁词分群词库 + 全局词库两级
链接 / 卡片 / 转发消息分别拦截
手机号自动识别手机号格式
QQ 号自动识别纯数字账号
刷屏时间窗口 + 条数阈值判定
全撤模式非白名单、非管理员的消息一律撤回（最严格的一档）

处置档位：警告 / 撤回 / 禁言 / 踢出（可带拉黑），每项检测可单独指定。

处罚升级：可以设置「警告 N 次后自动禁言」，也可以设置阶梯禁言（第 1/2/3 次违规分别禁言不同时长，超出次数沿用最后一档）。所有违规都会记进违规记录，可按人查看与清除。

命中处罚时，如果开了「回执提醒」，群里会播报处理结果。

二、入群验证与审批 ​

入群验证：新人进群先答题（算术题，QQ 官方平台会带按钮选项），验证期内发言会被撤回；答错按阶梯延长冷却。可配置：

  • 验证有效期（默认 5 分钟，答错后自动翻倍，有上限）
  • 验证期间是否禁言
  • 免验证名单：名单内的人进群直接放行

入群审批：有人申请入群时，把申请播报到群里（QQ 官方平台带「同意 / 拒绝」按钮），也可以：

  • 用指令审批：同意 <编号> / 拒绝 <编号> [原因]
  • 设置审批策略：手动 / 自动通过 / 自动拒绝 / 自动拉黑
  • 关键词审批：申请留言命中关键词时自动通过

三、成员处置 ​

  • 禁言：禁言 @成员 [分钟]、禁言 <用户ID> [分钟]，也可以引用某人的消息后直接发 禁言 10
  • 永久禁言：受平台单次禁言上限约束，本插件用「平台上限 + 到期自动续期」实现
  • 踢出：踢出 @成员 [拉黑]
  • 另有针对撤回名单（名单内成员的消息全部自动撤回）、撤回最近 N 条、禁言记录与单人禁言状态查询

四、黑白名单 ​

名单作用
黑名单该成员的消息被撤回，其指令被忽略
白名单该成员免于本插件的全部处罚与拦截（信任名单）

各自都有「本群」与「全局」两份。同时出现在两个名单里时，白名单优先。

五、授权系统（把群管当服务卖时用） ​

默认不启用，不影响任何群。启用「授权模式」后，未授权的群不会执行拦截、也不响应群管指令（主人和副主仍然可用，方便现场处理）。

  • 给当前群或指定群授权：30 天 / 90 天 / 永久，可以带备注
  • 随时查询某群剩余天数、清除单个或全部授权
  • 到期提示：快到期时（默认剩余 3 天内）在群里提醒一次，每天最多一次

六、问答 / 统计 / 签到 / 定时 ​

系统能做什么
问答精准问答（整词相等）与模糊问答（包含即命中），各有「本群」与「全局」两套；精准问你好答你好呀 这样增删查
统计发言日榜 / 周榜 / 月榜，我的发言与我的统计，进群 / 退群统计；可开关「榜单记录」与「榜单查询权限」
签到签到 得随机积分（默认 5~15），连续签到有额外奖励；有日榜与总榜；货币名称、奖励区间、连续签到目标都可配
定时添加定时 21:30#晚上好，到点自动往群里播报；支持开关与删除

统计与榜单默认是关的

「榜单记录」默认关闭（避免一装就产生持续增长的存储）。需要时在面板或群里发「开启榜单记录」。

定时播报依赖平台授权

定时消息属于主动消息，在没授权的群会发送失败（属平台限制，不是插件故障）。失败只记审计，不会刷屏。

七、入群 / 退群提示 ​

可以分别设置入群提示与退群提示的文案并单独开关，群里有人进出时自动播报。

和「入群欢迎」插件的关系

群管自带的提示更完整（支持退群提示）；独立的「入群欢迎」插件保留给只需要欢迎语的场景。两者可以同时装，不冲突。

八、常用指令速查 ​

在群里 @ 机器人发「群管菜单」，会按分组列出全部指令。发分组名（例如「处罚管理」）可以只看该组的指令，不用记完整的指令表。

想看当前各功能的开关状态，发「群管状态」——总开关、违禁词、卡片、转发、链接、入群验证、刷屏、问答、全撤、手机号、Q 号一次列全。

所有面向用户可见的文案都可以改：面板「回复模板」里有 100 多条模板，支持 Markdown 与纯文本两版，改完立即生效。

九、自定义菜单内容 ​

面板「菜单设置」页可以改菜单。规则只有一句：框里写什么，群里就收到什么。

菜单由若干「页」构成，每页就两样东西——触发词和一整段正文：

页触发词说明
主菜单群管菜单（固定）群里发「群管菜单」展开
分组页自己定，默认是「开关设置」「处罚管理」这些群里发这个词展开这一页

改正文就是直接改群里收到的那段文字——没有单独的页脚、版本行、用法行之类的设置项，想写什么（包括分隔线、版本号、提示语）都直接写在正文里。

  • 触发词也能改：把「开关设置」改成「功能开关」，群里就得发「功能开关」才展开。触发词必须唯一，重名会保存失败并提示。
  • 可以增删、调顺序：分组页列表里每行都能上移/下移/删除，也能新增一页。
  • 分组页默认是折叠的，点开才编辑正文。
  • 主菜单是手写的：增删分组后不会自动同步，要自己回去改主菜单正文。

Markdown：每页可以单独开 ​

每一页（含主菜单）都有一个 Markdown 开关：

  • 关（默认）：按纯文本发。所有平台都能正常显示。
  • 开：按 Markdown 发，可以写标题 #、加粗 **、列表 -、分隔线 ---。

开 Markdown 前先确认这两件事

  1. 只有 QQ 官方机器人能用。OneBot 等其它平台一律纯文本，写了 md 语法会原样显示出来。
  2. 该群不能关掉 Markdown（在面板「群配置」里）。群关掉了，同样会退回纯文本。

两个条件都满足时才会真正发 Markdown。所以不确定的话，先关着更保险。

正文里能用的变量 ​

变量替换成
{状态}当前各功能开关的实时开关状态（总开关、违禁词、刷屏……）
{名称}本页的触发词

默认的「群管状态」分组页，正文就是 {状态}，所以它显示的一直是最新状态。你把 {状态} 从正文里删掉，它就变成一段静态文字了。

没有"自动列出分组"的变量

主菜单也是完全手写的。增删或改名分组后，主菜单不会自动跟着变，要你自己回去改主菜单正文—— 这是"完全自定义"换来的自由（想怎么排就怎么排），代价就是要自己保持同步。

改菜单不会影响指令能不能用

菜单只是显示层。从菜单里删掉「禁言」，群里发「禁言」照样生效；反过来，写一个不存在的词也点不动任何东西。

所以菜单可以放心大胆地精简成你真正想要的样子。

「补全内置分组」按钮是干什么的

菜单一旦改过，就整份由你接管——以后插件版本升级新增的内置分组不会自动出现（因为你那份已经被你改过了）。 点「补全内置分组」会把内置菜单里有、你当前没有的分组补回来，不影响你已经改过的内容。

恢复默认有两个粒度：「全部恢复默认」清掉所有自定义回到出厂状态；每个分组页旁边还有单独的「恢复本页」。
