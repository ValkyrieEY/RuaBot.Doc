# 插件市场审核

> 审核开发者上传的插件，把控市场质量与安全。

## 审核流程

开发者上传插件后（默认不上架，见[发布与上架](../plugin-dev/publish)），需要平台审核才能正式进入市场：

1. **待审核**：开发者提交上架申请。
2. **审核中**：管理员查看插件。
3. **通过**：插件在市场上架，可被购买。
4. **拒绝**：附原因退回，开发者修改后重新提交。

## 审核要点

审核一个插件时关注：

- **功能正常**：核心功能能否跑通，有没有明显 bug。
- **安全合规**：没有恶意行为（偷数据、挖矿、后门），不违规。
- **代码质量**：异常处理是否到位，会不会拖垮运行时。
- **描述准确**：`meta.yaml` 的描述与实际功能一致。
- **配置合理**：`setting.json` 字段有默认值、说明清楚。

::: tip 可以装到测试机器人验证
审核时把插件装到一个测试机器人上，实际发消息验证功能，比光看代码更可靠。
:::

## 插件管理

| 操作 | 说明 |
|------|------|
| **下架** | 已上架插件发现问题，临时下架 |
| **强制停用** | 紧急停用某个有问题的插件 |
| **分类调整** | 调整插件分类 |
| **删除** | 彻底移除（慎用，影响已购买用户） |
