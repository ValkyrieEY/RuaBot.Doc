# 管理后台总览

> **你会学到**：管理后台能做什么、各功能模块概览。

管理后台是**平台运营方**使用的管理界面，登录入口在 `/admin/login`。用安装时创建的超级管理员账户登录。

## 核心模块

| 模块 | 作用 |
|------|------|
| [数据看板](#数据看板) | 平台运营数据总览 |
| [用户管理](./users) | 管理租户用户、余额、角色 |
| [适配器集群](./adapters) | 平台适配器与运行节点 |
| [插件市场审核](./marketplace) | 审核开发者上传的插件 |
| [订阅与计费](./subscriptions) | 套餐、卡密、订阅用户 |
| [开发者管理](./developers) | 开发者审批、提现 |
| [内容与公告](./content) | 公告、弹窗通知 |
| [系统设置](./settings) | 站点、邮件、支付、注册等 |
| [审计与日志](./audit) | 操作审计、运行日志 |

## 数据看板

后台首页是数据看板，展示平台关键运营指标：

- 用户数、活跃用户
- 机器人数量、运行状态
- 订阅收入、余额流水
- 插件市场销量
- 适配器 / 插件运行时状态

用于快速掌握平台整体运营情况。

## 权限说明

- **超级管理员**：拥有所有权限。
- **普通管理员**：按 [RBAC](../guide/features#rbac-权限与审计) 分配的权限，只能操作授权范围内的模块。
- 所有管理操作都会记录到[审计日志](./audit)。
