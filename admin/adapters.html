适配器集群 ​

管理平台接入的各个 IM 平台适配器及其运行节点。

适配器列表 ​

后台展示所有 支持的平台 适配器：

信息说明
适配器名称QQ 官方、Telegram、Discord 等
连接模式Webhook / WebSocket / 反向 WS / 轮询
状态在线 / 离线
启用状态启用 / 停用
版本适配器版本号

启用 / 停用 ​

  • 停用适配器：该平台下所有机器人暂停服务，不再收发消息。
  • 启用适配器：恢复服务。

停用不删数据

停用适配器只是暂停运行，机器人和配置都保留，重新启用即恢复。

运行节点 ​

适配器以子进程运行，支持多节点：

  • 查看每个适配器的运行节点状态（运行中 / 异常）。
  • 监控节点健康、事件处理情况。
  • 节点异常时会告警，可手动重启。

Webhook 回调地址 ​

Webhook 类适配器（QQ 官方、飞书等）需要把回调地址配到平台后台：

  • 后台会显示该适配器的回调地址。
  • 把地址填到对应平台的应用配置里。

回调地址需 HTTPS

Webhook 回调地址必须是公网可访问的 HTTPS。先配好 Nginx + SSL。
