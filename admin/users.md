# 用户管理

> 管理平台上的租户用户（你的客户）。

## 用户列表

查看所有注册用户，支持搜索、筛选、分页。每条记录显示：

- 用户名、邮箱、QQ 号
- 角色（普通用户 / 管理员）
- 状态（正常 / 禁用）
- 余额
- 订阅状态
- 注册时间

## 常见操作

| 操作 | 说明 |
|------|------|
| **调整余额** | 给用户充值或扣减余额（手动调整，会留审计记录） |
| **重置密码** | 帮忘记密码的用户重置 |
| **禁用 / 启用** | 封禁违规用户，或恢复 |
| **修改角色** | 提升为管理员，或调整权限 |
| **查看详情** | 查看用户的机器人、订阅、购买记录 |

## 角色与权限

- **普通用户**：只能用用户控制台，管理自己的机器人。
- **管理员**：可访问管理后台，按分配的权限操作。
- **超级管理员**：全部权限。

详细权限分配见 [系统架构 · RBAC](../guide/architecture)。

::: warning 谨慎操作
调整余额、修改角色等操作都会记入[审计日志](./audit)，谁操作的、改了多少，全程可追溯。
:::
