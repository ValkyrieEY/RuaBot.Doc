审计与日志 ​

查看操作审计日志和运行日志，追溯问题。

审计日志 ​

V3 记录管理后台和用户控制台的所有关键操作：

  • 谁（哪个账号）
  • 在什么时候
  • 做了什么操作（调整余额、修改配置、审核插件……）
  • 操作前后的关键数据

用途：

  • 追溯：出问题时快速定位是谁、何时改了什么。
  • 合规：满足安全审计要求。
  • 防滥用：管理员操作全程留痕，互相监督。

支持按时间、操作人、操作类型筛选查询。

安全日志 ​

记录安全相关事件：

  • 登录成功 / 失败
  • 异常访问、被拦截的请求
  • 授权校验事件
  • IP 黑名单触发

用于发现异常登录、暴力破解等安全威胁。

运行日志 ​

查看系统运行状态日志：

日志类型内容
主服务日志启动、请求、异常
适配器日志各平台事件接收、发送
插件日志插件 context.log() 写的日志、异常

排查插件问题

某个插件不工作？看插件运行日志，找该插件的 code，看是否有报错或没收到事件。

容器日志（命令行） ​

后台看不够时，用命令行看完整日志：

bash
docker compose logs -f xiaoyi              # 全部日志
docker compose logs -f xiaoyi | grep 错误  # 过滤错误
