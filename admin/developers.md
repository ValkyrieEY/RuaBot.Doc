# 开发者管理

> 管理插件开发者：审批入驻、查看销量、处理提现。

## 开发者入驻审批

用户可申请成为插件开发者。管理员审批：

- 查看申请者的基本信息。
- 通过 / 拒绝申请。
- 通过后该用户获得开发者中心权限，可上传插件。

## 开发者列表

查看所有开发者：

| 信息 | 说明 |
|------|------|
| 开发者资料 | 用户名、联系方式 |
| 已发布插件 | 数量、列表 |
| 累计销量 | 插件总销售额 |
| 可提现余额 | 待提现金额 |
| 分成比例 | 该开发者的分成配置 |

## 分成比例

- 可为每个开发者配置分成比例（平台与开发者的收益分配）。
- 客户购买付费插件时，按比例计算开发者收益，进入开发者余额。

## 提现管理

开发者申请提现后，管理员处理：

1. **审核提现申请**：核对金额、账户。
2. **打款**：线下/线上完成打款。
3. **标记完成**：在后台标记该笔提现已处理。

所有提现有完整记录，便于对账。

::: warning 提现审核要仔细
提现涉及资金，务必核对开发者身份和账户信息，确认无误后再打款。所有操作留审计记录。
:::
