# 订阅与计费

> 管理订阅套餐、卡密、用户订阅、计费配置。

## 订阅套餐（Plan）

定义可供用户购买的套餐规格：

| 配置项 | 说明 |
|--------|------|
| 计费模式 | 月付 / 年付 / 永久 / 自定义 |
| 价格 | 套餐价格 |
| 机器人配额 | 可创建的机器人数量 |
| 插件配额 | 可安装的插件数量 |
| 包含插件 | 套餐内含哪些插件（白名单或全部） |
| 适配器权限 | 套餐可用哪些平台适配器 |

::: tip 配额自动管控
用户的订阅决定其资源配额。订阅过期后资源自动降级（机器人停用、插件停用，但**不删数据**），续费即恢复。
:::

## 卡密系统

生成可兑换的卡密，分三类：

| 卡密类型 | 兑换内容 |
|---------|---------|
| **套餐卡** | 兑换一个订阅套餐 |
| **余额卡** | 充值到账户余额 |
| **插件卡** | 兑换某个付费插件 |

操作：

- **批量生成**：一次性生成多张卡密。
- **导出**：导出卡密列表分发给渠道。
- **作废**：失效未使用的卡密。
- **使用记录**：查看每张卡密被谁兑换。

## 订阅用户

查看所有用户的订阅状态：

- 当前订阅套餐、到期时间。
- 续费记录。
- 手动延期 / 调整套餐（用于处理客诉、赠送）。

## 支付配置

支付集成在 [系统设置](./settings) 里配置：

- 彩虹易支付接口（V1 / V2 协议）。
- 商户号、密钥等。
- 充值档位设置。

::: warning 支付配置要保密
支付密钥属于敏感信息，配置后注意权限控制，不要泄露。
:::
