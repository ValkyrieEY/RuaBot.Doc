# 系统设置

> 配置平台级的系统参数。

## 站点设置

| 配置 | 说明 |
|------|------|
| 站点名称 | 显示在页面的品牌名 |
| Logo | 站点标志 |
| 备案信息 | ICP 备案号（底部展示） |
| 联系方式 | 客服 QQ / 邮箱等 |

## 邮件设置

配置 SMTP，用于系统邮件（注册验证、密码重置、通知等）：

| 配置 | 说明 |
|------|------|
| SMTP 服务器 | 如 `smtp.qq.com` |
| 端口 | 465（SSL）/ 587（TLS） |
| 发件账号 | 邮箱地址 |
| 授权码 | 邮箱的 SMTP 授权码 |
| 发件人名称 | 显示名 |

::: tip 先测试再启用
配置完 SMTP 后，先用测试邮件功能发一封验证能否正常收发，再开启依赖邮件的功能。
:::

## 支付设置

配置彩虹易支付（见[订阅与计费](./subscriptions#支付配置)）：

- 接口地址、商户号、密钥。
- 协议版本（V1 MD5 / V2 RSA）。
- 充值档位、自定义金额范围。

## Redis 设置

| 配置 | 说明 |
|------|------|
| Redis 地址 | 连接 URL |
| 启用 / 停用 | 是否启用 Redis 加速 |

Redis 不可用时自动降级为数据库轮询（见[环境要求](../deploy/requirements#可选组件)）。

## 注册设置

| 配置 | 说明 |
|------|------|
| 开放注册 | 是否允许新用户注册 |
| 邮箱验证 | 注册是否强制邮箱验证 |
| 注册赠送 | 新用户赠送余额 / 试用订阅 |
| 邀请奖励 | 邀请新用户的奖励 |

## 维护模式

开启后，除白名单接口外，所有访问返回维护中提示：

- 用于系统升级、数据迁移时临时屏蔽用户访问。
- 公共回调（如支付回调）仍可正常工作。

::: warning 维护模式期间
开启维护模式会让普通用户无法使用。升级完成后记得关闭。
:::

## IP 黑名单

封禁恶意 IP，被拉黑的 IP 无法访问平台。
