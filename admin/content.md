# 内容与公告

> 管理面向用户的公告、弹窗通知等运营内容。

## 公告管理

发布公告，展示在用户控制台 / 管理后台：

| 配置 | 说明 |
|------|------|
| 标题 / 内容 | 公告正文（支持富文本） |
| 生效时间 | 发布时间、过期时间 |
| 置顶 | 是否置顶显示 |
| 可见范围 | 全部用户 / 指定用户 |

适用场景：系统维护通知、新功能上线、活动公告。

## 弹窗通知

用户登录时弹出的通知窗口，比公告更显眼：

| 配置 | 说明 |
|------|------|
| 标题 / 内容 | 弹窗内容 |
| 触发时机 | 登录后弹出 |
| 显示频率 | 每次登录 / 仅一次 / 每天一次 |
| 关闭方式 | 可关闭 / 必须确认 |

适用场景：重要政策变更、强制升级提示、安全提醒。

::: tip 别滥用弹窗
弹窗会打断用户操作，体验上比公告更具侵入性。重要、紧急的内容才用弹窗，日常通知用公告即可。
:::
