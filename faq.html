常见问题 ​

部署相关 ​

Q：安装向导提交后提示"授权验证失败，提交参数不完整"？ ​

授权码为空且自动获取未成功。两种解法：

  • 在安装向导的授权码字段手动粘贴开发商给你的授权码，重新提交。
  • 或确认你的部署域名已在授权平台（sq.yuafeng.cn）登记。

详见 授权激活。

Q：容器起来了，但访问 /install 提示"前端构建未找到"？ ​

发布包不完整，前端静态文件缺失。重新解压完整发布包，或联系开发商获取完整包。

Q：安装时数据库连不上？ ​

容器内连宿主机上的数据库，地址不要填 localhost，用宿主机内网 IP 或 Docker 网关 172.17.0.1。云数据库填 RDS 地址，并确认安全组放行。详见 安装向导。

Q：安装成功，但登录管理后台提示"无权限"？ ​

权限未初始化。通常是安装流程被中断导致。联系平台方或重新走一次安装。

运行相关 ​

Q：机器人收不到消息？ ​

逐项排查：

  1. 适配器是否启用、状态在线（适配器集群）。
  2. 平台凭证是否正确、是否过期。
  3. Webhook 类：回调地址是否填到平台后台、是否 HTTPS 可访问。
  4. 机器人是否启用、订阅是否过期。
  5. 看运行日志（审计与日志）有没有事件接入。

Q：某个插件不工作？ ​

  • 该插件是否已绑定到机器人并启用（机器人管理）。
  • 插件订阅的事件类型对不对（比如只订阅 message.group，私聊就不会触发）。
  • 看插件运行日志有没有报错。
  • 改了插件代码 / 配置后是否重启了插件进程（配置有约 30 秒缓存）。

Q：QQ 官方机器人收不到群消息（没 @它）？ ​

QQ 官方默认只收 @机器人的消息。要收全部消息，在机器人的适配器设置里开启「全量消息当作普通群消息处理」。详见 事件类型。

Q：插件发的 Markdown / 按钮没效果？ ​

这些是部分平台（如 QQ 官方）支持的特性，不是所有平台都支持。在不支持的平台降级为纯文本。详见 发送消息。

Q：消息发不出去 / 发送失败？ ​

  • 检查内容是否触发平台审核（QQ 官方有消息审核）。
  • 撤回超过 2 分钟会失败（QQ 官方限制）。
  • 富媒体的 media_url 是否可访问。
  • 看运行日志的具体错误。

计费相关 ​

Q：订阅过期了，我的数据和插件还在吗？ ​

在。过期只是降级（机器人 / 插件停用），不删数据。续费后立即恢复。

Q：余额充值没到账？ ​

支付回调可能有延迟。如果长时间未到账，联系平台方核对订单（提供支付凭证）。

Q：卡密兑换失败？ ​

  • 卡密是否已过期 / 已使用。
  • 卡密类型是否匹配（套餐卡不能当余额卡用）。
  • 确认卡密复制完整（无多余空格）。

开发相关 ​

Q：插件上传后看不到？ ​

新插件默认 allow_purchase: false（不上架）。在控制台 / 开发者中心确认上架状态。市场插件还需平台审核。

Q：改了 main.py 不生效？ ​

插件代码在进程启动时加载，改完要重启插件进程才生效。配置（setting.json）改完有约 30 秒缓存延迟。

Q：插件数据怎么存？需要自己建表吗？ ​

不用。用 context.data_store 的键值接口，数据按 插件 + 用户 + 机器人 自动隔离。详见 数据存储。

Q：怎么让插件在所有平台通用？ ​

用 context.reply()、context.sender_id、context.chat_id 等统一接口，不要直接读平台原始字段。详见 跨平台开发。

没找到答案？联系平台方或看 运维与故障排查。
