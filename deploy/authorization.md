# 授权激活

> **你会学到**：V3 的域名授权机制、怎么激活、授权失败怎么办。

## 授权机制

V3 是**闭源商业产品**，采用**域名绑定授权**：

- 每个部署实例绑定到**一个域名**。
- 系统定期（约每 30 分钟）向授权云校验授权有效性。
- 校验通过后，本地保存一份加密缓存，断网时也能短时间正常运行。

::: tip 为什么用域名
授权绑定到域名，而不是机器硬件。这样你换服务器、迁移部署，只要域名不变，授权就跟着走，不用重新激活。
:::

## 如何激活

### 方式一：安装时自动获取（推荐）

在 [安装向导](./install) 里，授权码字段**留空**，系统会：

1. 从你访问的 Host 头提取域名。
2. 向授权云查询该域名绑定的授权码。
3. 自动获取并写入配置。

只要你的域名已在授权平台登记，这一步全自动。

### 方式二：手动填写

如果自动获取失败（域名未登记、网络问题等），直接在安装向导的授权码字段**粘贴**开发商发给你的授权码字符串，重新提交即可。

### 方式三：安装后补填

如果安装时没填授权码，可以编辑本地配置文件，在 `authorization.authcode` 字段填入授权码，然后重启容器。

## 前置条件

激活前，确保你的**部署域名已在授权平台（sq.yuafeng.cn）登记**：

- 联系开发商，把你的域名（如 `bot.example.com`）登记到授权后台。
- 登记后该域名会绑定一个授权码，自动获取才能成功。

## 常见问题

### 提示"授权验证失败，提交参数不完整"

通常是授权码为空且自动获取未成功。检查：

- 域名是否已在授权平台登记。
- 安装向导里是否手动填了授权码。

### 提示"该授权不存在"

你的域名未在授权平台登记，或登记的域名与实际访问域名不一致。联系开发商核实。

### 授权正常但后台进不去

检查 Nginx 是否正确转发了 `Host` 头（见 [Nginx 配置](./nginx#必须转发-host-头)）。授权靠 Host 头识别域名，转发丢了就会判定无授权。

### 断网后还能用多久

本地有加密授权缓存，断网后可短时间继续运行。网络恢复后会自动重新校验同步。

::: warning 不要尝试绕过授权
V3 关键模块受保护，绕过授权会导致系统无法正常运行。请通过正规渠道获取授权。
:::
