# 环境要求

> 部署 V3 前，请准备好以下环境。

## 服务器要求

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 2 核 | 4 核 |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 20 GB | 50 GB+ |
| 操作系统 | CentOS 7+ / Ubuntu 20.04+ / Debian 10+ | Ubuntu 22.04 / Debian 12 |

## 必需组件

| 组件 | 版本 | 说明 |
|------|------|------|
| **Docker Engine** | 24+ | 运行容器（推荐方式） |
| **Docker Compose** | v2 | 编排容器 |
| **PostgreSQL** | 13+ | 主数据库，**需自备**，V3 不内置 |
| **域名** | — | 绑定授权用，建议已备案并解析到服务器 |

## 可选组件

| 组件 | 版本 | 说明 |
|------|------|------|
| **Redis** | 6+ | 提升事件通知性能；不装也能跑，自动降级 |
| **Nginx** | — | 反向代理 + HTTPS，生产环境强烈推荐 |

::: tip 数据库要自备
V3 容器**不包含** PostgreSQL。你需要自行准备一个 PostgreSQL 数据库（云数据库 RDS 或服务器自建均可），在安装向导里填连接地址。
:::

::: warning Redis 的作用
Redis 只影响**性能**，不影响功能正确性。有 Redis 时事件通知更快；没有时自动降级为数据库轮询。小规模部署可以不装，但建议生产环境配上。
:::

## 网络

- 开放一个端口给 V3 容器（默认 `8000`），或通过 Nginx 反代。
- 服务器需能访问授权云服务（用于域名授权校验）。
- 如使用 Webhook 类适配器（QQ 官方等），平台需能从公网回调到你的服务器。

## 授权准备

V3 是闭源商业产品，部署前需要：

1. 在授权平台（sq.yuafeng.cn）把你的**部署域名**登记并绑定授权。
2. 部署时安装向导会根据访问域名**自动获取授权码**；如自动获取失败，可手动粘贴授权码。

详见 [授权激活](./authorization)。
