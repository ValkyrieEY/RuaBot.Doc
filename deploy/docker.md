# Docker 部署

> **你会学到**：用一键脚本把 V3 跑起来。

V3 提供**一键部署脚本** `install.sh`，封装了加载镜像、配置端口、启动容器、健康检查的全流程，无需懂 Docker 命令。

## 前置条件

- 已安装 Docker Engine 24+ 和 Docker Compose v2。
- 已准备好 PostgreSQL 数据库（[环境要求](./requirements)）。
- 已拿到 V3 发布包（含镜像 tar 和部署文件）。

::: tip 验证 Docker
```bash
docker --version        # 应显示 24+
docker compose version  # 应显示 v2.x
```
:::

## 一键部署

解压发布包后，目录里会有 `install.sh`。执行：

```bash
bash install.sh
```

脚本会依次完成：

1. **检查环境** —— 确认 Docker / Compose 已安装。
2. **加载镜像** —— `docker load` 导入 V3 镜像 tar 包。
3. **配置端口** —— 询问你要暴露的端口（默认 8000）。
4. **启动容器** —— `docker compose up -d`。
5. **健康检查** —— 轮询 `/api/health` 直到服务就绪。

脚本结束后会提示访问地址。

## 端口映射说明

容器内部固定监听 `8000`。你在脚本里填的端口是**宿主机端口**，映射关系是 `宿主机端口:8000`。

```
你的端口 8000  →  容器内 8000
```

::: tip 配合 Nginx
生产环境建议让 V3 只监听本地（`127.0.0.1:端口`），由 Nginx 反代到公网。这样更安全，也方便配 HTTPS。详见 [Nginx 反向代理](./nginx)。
:::

## 首次安装

容器启动后，浏览器访问：

```
http://服务器IP:端口/install
```

按 [安装向导](./install) 填写数据库连接、创建管理员、自动获取授权码。

## 升级部署

发布新版本时，把新的发布包覆盖到部署目录，再跑一次 `install.sh`：

- 脚本会自动停掉旧容器、启动新容器。
- 数据在 volume 里持久化，**不会丢失**。

::: warning 在线更新 vs 重新部署
- 小版本更新：用后台「在线更新」即可，无需重新部署（见 [在线更新](./update)）。
- 大版本 / 镜像变更：重新跑 `install.sh` 覆盖部署。
:::

## 卸载

部署包附带 `uninstall.sh`，支持多级别清理（只停容器 / 删数据 / 彻底删除）。详见 [运维与备份](./ops#卸载)。
