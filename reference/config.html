配置项 📋 ​

这页是 config/bot.toml 的完整参考。文件按 [段] 组织，下面逐个段落列出键名、默认值与说明。改了配置文件必须重启服务才生效（面板里改的除外，见文末）。

文件位置：.deb 安装后在 /opt/xiaoyi_qq_c/config/bot.toml。

[app] 应用信息 ​

键名默认值说明
name"xbot"应用名称，用于日志与界面标识
env"development"运行环境。安装向导写入的是 production；在 production 下找回密码等流程遵循生产安全策略，不再返回开发链接

[server] 监听地址 ​

键名默认值说明
data_listen"0.0.0.0:8081"适配器数据面监听地址。QQ 平台侧的连接（如 OneBot 反向 WS）走这里
admin_listen"0.0.0.0:8080"控制台 / Web 界面监听地址
frontend_embedfalse是否使用内嵌前端资源。默认 false，前端已编译进二进制，通常无需改动

[log] 日志 ​

键名默认值说明
level"info"日志级别，可选 trace / debug / info / warn / error。排障时临时调低
dir"logs"日志文件输出目录（相对程序目录）
jsonfalse是否输出结构化 JSON 日志，便于对接日志采集系统

[threads] 线程数 ​

键名默认值说明
io_data0数据面 IO 线程数。0 表示按 CPU 核数自动决定
worker0工作线程数。0 表示按 CPU 核数自动决定
admin8控制台 / 管理接口线程数。安装向导生成的配置会写 2；机器配置低时保持小值即可

[database] 数据库 ​

键名默认值说明
host"localhost"PostgreSQL 地址。安装向导会写入你在向导里填的值（常见是 127.0.0.1）
port5432PostgreSQL 端口
user""数据库用户名
password""数据库密码
dbname""数据库名
pool_size10连接池大小

这些值由安装向导写入

首次配置时向导会把你在页面上填的内容写进这一段。手工改这里之后记得重启服务，并用 /readyz 确认数据库连得上。

[payment] 支付 ​

键名默认值说明
enabledfalse是否启用在线支付
apiurl""支付网关接口地址
pid""支付网关商户号
key""支付网关商户密钥
sign_type""签名方式，默认为 MD5
private_key""商户私钥（网关要求非对称签名时使用）
public_key""网关公钥，用于校验回调
sitename""站点名称，展示在支付页
notify_url""异步回调地址
return_url""同步跳转地址

[smtp] 邮件 ​

键名默认值说明
enabledfalse是否启用邮件发送（注册验证码、找回密码等）
host""SMTP 服务器地址
port465SMTP 端口
user""SMTP 用户名
password""SMTP 密码 / 授权码
from""发件人地址
from_name""发件人显示名称
ssltrue是否使用 SSL 直连（对应 465 端口）
starttlsfalse是否使用 STARTTLS 升级（通常与 ssl 二选一）

[retention] 数据保留 ​

控制自动清理策略，程序每 6 小时执行一次清理。天数设为 0 表示永久保留、不清理。

键名默认值说明
event_days7消息留痕保留天数
notify_days30通知保留天数
audit_days90审计日志保留天数
user_log_days90用户日志保留天数
ai_conv_days30AI 会话保留天数
kv_days0插件 KV 保留天数，0 表示永久
interval_hours6自动清理的执行间隔（小时）

[[plugin]] 内置插件装载（一般不用改） ​

配置文件里还可以有多个 [[plugin]] 段，用来声明随程序分发的内置插件：

toml
[[plugin]]
code     = "echo"          # 插件标识
so       = "plugins/libecho.so"
enabled  = true
priority = 1000
  • 这一段只影响内置插件的装载；从控制台上传的插件、以及「插件装到哪台机器人」的绑定关系，都存在数据库里，由控制台管理。
  • 数据库里没有任何插件记录时，程序才会回退用这里的配置。正常通过控制台装插件的用户不需要改这段。

哪些配置在面板里也能改 ​

下面这些不用改文件，在控制台「平台设置」里就能改，且面板里的值会覆盖配置文件：

  • 支付相关配置
  • SMTP 邮件配置
  • 站点域名
  • 注册策略
  • AI 助手

所以排查「我明明改了配置文件怎么没生效」时，先去「平台设置」看一眼是不是面板里有值把它盖掉了。

改完要重启吗 ​

改法是否要重启
直接编辑 config/bot.toml需要重启服务：sudo systemctl restart xiaoyi-qq-c
在控制台「平台设置」里改立即生效，不需要重启
