# 接入方式总览 🌐

Xiaoyi_QQ_V4 目前提供两种适配器（adapter）：直接对接 **QQ 官方开放平台**，或通过 **OneBot 11** 接入第三方 QQ 实现端。这页把两者的连接方式、能力边界和部署成本摆在一起，帮你决定走哪条路。

换适配器意味着换一套平台侧配置、有时还意味着换一个 QQ 号，所以在动手之前建议先看完这页。

## 1. 一张表看清两种适配器

| 对比项 | `qq_official`（QQ 官方） | `qq_onebot`（OneBot 11） |
|---|---|---|
| 机器人身份 | QQ 开放平台上注册的官方机器人 | 你自己登录的 QQ 号 |
| 支持的连接方式 | Webhook 回调、WebSocket 网关 | 仅反向 WebSocket |
| 需要公网域名吗 | Webhook 模式需要；WebSocket 网关模式不需要 | 不需要，但要保证实现端能连到框架 |
| 按钮 / Markdown 消息 | 支持 | 不渲染按钮与富文本，需改走纯文本 |
| 禁言 / 踢人等群管理 | 支持，但不少接口需要平台单独开权限 | 走 OneBot 标准接口，同样可用 |
| 入群审批 | 支持（QQ 官方专属能力） | 不可用 |
| 你要额外部署什么 | 无，只需在 QQ 开放平台注册配置 | 自己部署一个实现端（NapCat / Lagrange / go-cqhttp 等） |
| 适配器标识 | `qq_official` | `qq_onebot` |

## 2. 选哪一个

**选 QQ 官方，如果你：**

- 希望走平台官方渠道，机器人是「官方机器人」身份
- 需要按钮、Markdown 这类富文本交互
- 需要入群审批这类 QQ 官方专属能力
- 不想额外维护一个常驻的实现端进程

代价是：很多群管理接口默认不开，需要你去 QQ 开放平台为机器人申请对应权限；群内要免 @ 收到全量消息，也需要单独授权。

**选 OneBot 11，如果你：**

- 需要的能力主要落在群管理上（禁言、踢人、撤回等）
- 手头已经有一台跑着 NapCat / Lagrange / go-cqhttp 的机器
- 不介意自己部署、登录并长期维护实现端

代价是：富文本能力会打折，按钮和 Markdown 发出去会变成纯文本；入群审批这类官方专属能力用不了。

::: tip 两者可以并存
一个 Xiaoyi_QQ_V4 实例可以同时接入多个机器人，官方机器人和 OneBot 机器人可以共存，各自独立配置插件。具体数量上限由你的套餐决定，见 [订阅 · 卡密 · 充值](/console/billing)。
:::

## 3. 连接方式怎么选

`qq_official` 有两种连接方式，区别只在于「谁来发起连接」：

| 连接方式 | 谁主动 | 要不要公网域名 | 适合场景 |
|---|---|---|---|
| WebSocket 网关（推荐） | 框架主动连平台 | 不需要 | 绝大多数情况，尤其是没有公网域名的服务器 |
| Webhook 回调 | 平台回调你的服务 | 需要 | 已经有稳定公网域名、希望回调直连的场景 |

`qq_onebot` 只有一种连接方式：**反向 WebSocket（reverse WebSocket）**——实现端主动连到框架，框架不需要对外暴露任何地址。

三条具体路径：

- [QQ 官方：WebSocket 网关](/platforms/qq-official)（推荐，最省事）
- [QQ 官方：Webhook 回调](/platforms/qq-official-webhook)
- [QQ OneBot 11](/platforms/qq-onebot)

## 4. 创建机器人的两条路径

不管选哪种适配器，最后都要回到控制台的「我的机器人」页面把机器人加进去。区别在于**前置准备在哪做**：

**路径 A：QQ 官方**

1. 先去 QQ 开放平台创建机器人应用，拿到 `AppID` 与 `AppSecret`
2. 在 QQ 开放平台为机器人配置需要的权限
3. 回到控制台 [我的机器人](/console/bots)，点「添加机器人」，平台选 `qq_official`

**路径 B：OneBot 11**

1. 先在你自己的机器上部署实现端（NapCat / Lagrange / go-cqhttp）并登录 QQ
2. 回到控制台 [我的机器人](/console/bots)，点「添加机器人」，平台选 `qq_onebot`
3. 控制台会给出一个反向 WS 地址，把它填回实现端

两条路径在控制台里是同一个「两步向导」，第二步的内容会随你选的平台变化。

## 5. 通用前置检查

不管走哪条路，动手前先确认这几件事：

- 服务已经在运行，并且你能登录控制台（见 [安装](/deploy/install)）
- 你手上有一个可用的 QQ 号或已注册的官方机器人
- 机器人的数量没有超出套餐额度（套餐决定你能建几个机器人，见 [订阅 · 卡密 · 充值](/console/billing)）
