产品介绍 ​

你会了解到：小依 QQ V3 是什么、解决什么问题、适合谁用。

这是什么 ​

小依 QQ V3（以下简称 V3）是一个多租户的 QQ 机器人 SaaS 管理平台。

简单说：你部署一套 V3，就能同时为很多个客户各自提供独立的 QQ 机器人服务——每个客户有自己的机器人、自己的插件、自己的订阅和数据，彼此完全隔离，而你用一个统一的后台管理所有人。

它解决什么问题 ​

如果你做过 QQ 机器人，大概率踩过这些坑：

  • 一人一套代码：给每个客户部署一次、升级一次、出问题排查一次，运维成本随客户数线性增长。
  • 插件无法复用：A 客户要签到、B 客户要积分商城，功能各写一遍，没法沉淀成生态。
  • 没法商业化：没有订阅、计费、卡密，机器人做得再好也难变现。
  • 多平台割裂：QQ 官方、Telegram、Discord 各一套逻辑，换个平台要重写。

V3 用一套架构解决上面全部问题：

痛点V3 的解法
一人一套代码多租户：一套系统服务所有客户，数据天然隔离
插件无法复用插件市场：开发者写一次，所有客户、所有平台通用
没法商业化订阅计费：套餐、卡密、余额、分成，开箱即用
多平台割裂XUBP 协议：一套接口，九大平台通用运行

适合谁 ​

  • 平台运营方：想做一个"卖机器人服务"的生意，需要多租户 + 计费 + 后台管理。
  • 插件开发者：会写点 Python，想把自己的机器人功能做成插件卖给平台上的客户、赚取分成。
  • 企业 / 团队：内部需要管理多个 QQ 机器人，希望统一管控、权限分明、有审计。

核心能力一览 ​

  • 🤖 九大平台适配器：QQ 官方、OneBot、Telegram、Discord、KOOK、飞书、钉钉、微信公众号、企业微信
  • 🧩 插件市场：上传、定价、上架、收益分成、版本管理
  • 💳 订阅与计费：月/年/永久套餐、卡密兑换、余额充值、彩虹易支付
  • 🏢 多租户隔离：机器人、插件数据、订阅按客户隔离
  • 🛡️ RBAC 三级权限：管理后台 / 用户控制台 / 开发者中心，细粒度控权 + 全操作审计
  • 🔄 在线更新：后台一键升级，增量更新 + 自动重启
  • 🔌 Open API：对外提供 API Key，方便二次集成
