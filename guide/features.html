核心特性 ​

你会了解到：V3 的核心优势，以及每项能力背后的设计思路。

一、多租户 SaaS 架构 ​

V3 从第一天就按多租户设计：一套部署，服务无数客户。

  • 每个客户（租户）有独立的机器人实例、插件配置、订阅、余额。
  • 数据按租户隔离，A 客户绝对看不到 B 客户的任何数据。
  • 所有租户共享同一套适配器和插件市场，但各自的运行时互不干扰。

为什么重要

传统"一客一套"模式，运维成本随客户数线性增长。多租户让你用一套系统的运维成本，服务成百上千个客户。

二、插件市场与开发者生态 ​

V3 内置完整的插件交易市场：

  • 开发者中心：第三方开发者注册成为开发者，上传插件、管理版本。
  • 定价上架：插件可免费或付费，开发者自主定价。
  • 收益分成：客户购买插件的收入，按平台与开发者的分成比例结算，开发者可提现。
  • 审核机制：平台管理员审核上架的插件，把控质量与安全。
  • 一次编写，处处运行：插件基于 XUBP 协议 开发，同一份代码在所有平台通用。

三、订阅与计费体系 ​

完整的商业化闭环：

能力说明
订阅套餐支持月付、年付、永久、自定义；按套餐分配机器人数量、插件数量等配额
卡密系统生成套餐卡、余额卡、插件卡，客户用卡密兑换
余额充值预设充值档位 + 自定义金额，余额可购买插件、续订
支付集成内置彩虹易支付，支持 V1 / V2 协议
配额管控订阅过期自动降级资源（不删数据），续费即恢复

四、分布式适配器架构 ​

每个平台适配器和每个插件都以独立子进程运行：

  • 故障隔离：一个插件崩溃，不会拖垮其他插件或主进程。
  • 自动恢复：进程崩溃后可配置自动重启；父进程退出时子进程安全退出。
  • 可靠投递：事件通过持久化队列传递，保证不丢失；Redis 不可用时自动降级。
  • 可扩展：适配器支持多节点，应对高并发场景。

详见 系统架构。

五、RBAC 权限与审计 ​

三套独立角色，权限粒度到每个操作：

  • 管理后台：平台级管理——用户、适配器、市场、订阅、开发者、内容、设置、审计。
  • 用户控制台：租户自助——创建机器人、装插件、管理订阅、充值。
  • 开发者中心：插件开发者——上传插件、看销量、提现。

全操作审计

管理后台和用户控制台的所有关键操作都会记录审计日志，谁在什么时候做了什么，全程可追溯。

六、在线更新 ​

  • 后台一键检测云端新版本。
  • 增量下载更新包，只替换变化的文件。
  • 更新完成后自动重启服务（可配置），无需 SSH 登录服务器。
  • 支持 SQL 迁移脚本随版本一起执行。

七、域名授权保护 ​

V3 是闭源商业产品，采用域名绑定授权：

  • 每个部署实例绑定到一个域名，云端定期校验授权有效性。
  • 授权码可在安装时根据访问域名自动获取，无需手动查找。
  • 离线/断网时使用本地加密缓存，网络恢复后自动同步。

详见 授权激活。
