核心特性 ​

这页把主要能力逐项展开，方便你判断它能不能满足需求。每一项都给出「怎么用」和「对应文档」。

机器人接入 ​

支持两类适配器，都在控制台「添加机器人」里两步完成：

适配器连接方式适合
QQ 官方机器人WebSocket 网关（推荐）、Webhook 回调合规运营、需要按钮与 Markdown 消息
OneBot 11反向 WebSocket已有 NapCat / Lagrange / go-cqhttp 等实现端，需要更全的群管理能力
  • 创建机器人后立即上线，不需要重启服务；删除机器人同理。
  • 每台机器人的插件安装、配置、日志、消息记录都是独立的。
  • 机器人详情页能直接看到连接状态、适配器信息、以及该机器人当前支持哪些平台能力。

详见 机器人接入。

插件体系 ​

插件是独立的 .so 文件，装到某台机器人上运行，可以：

能力场景举例
接收事件群消息、私聊消息、成员入群/退群、入群申请、按钮点击
拦截与改写命中违禁词时撤回、把消息内容改写后再交给后面的插件
主动发消息欢迎新成员、定时播报、审批结果回执
存取数据记分板、签到、统计计数（按插件 + 机器人隔离）
保存配置每个机器人一份配置，改完立即生效
调用平台能力禁言、踢人、撤回、审批入群、查群信息
出站请求调用你自己的 HTTP 接口，把结果加工后回复
自带 Web 面板插件可以有自己的可视化配置页，直接在控制台里打开
  • 接口稳定：插件接口只增不改，框架升级不需要重新编译已有插件。
  • 一个头文件即 SDK：不需要额外依赖，编译产物就是一个 .so。
  • 跨平台一致：插件只面对统一事件与统一调用接口，同一份代码换平台不用改。

详见 插件开发。

社群管理（内置插件） ​

框架自带一套社群管理能力，装在机器人上就能用：

  • 内容拦截：违禁词（支持全局词库 + 分群词库）、链接、卡片/小程序、转发消息；
  • 刷屏检测：按时间窗口与条数阈值判定，可配撤回 / 禁言 / 踢出；
  • 成员处置：禁言、解禁、踢出（可同时拉黑）、针对某人自动撤回其消息；
  • 入群管理：入群验证（答题）、入群审批（手动 / 自动通过 / 自动拒绝 / 自动拉黑）、申请播报与一键审批；
  • 审计与统计：所有处置动作都有记录，可查、可持久化。

在 QQ 官方平台下，审批播报会带上可点击的按钮；其它平台不会渲染按钮，此时用文字指令完成同样的操作（例如回复「同意 1」）。

可视化管理 ​

页面你能看到什么
仪表盘机器人数量、运行概况、近期事件
机器人详情插件启停、事件转发配置、消息记录、运行日志、支持能力
服务器监控CPU、内存、进程占用、运行时长、消息吞吐
插件面板插件自己的配置界面
通知中心订阅变化、充值、卡密兑换、安全事件提醒

日志与消息记录都带自动清理策略（默认保留 7–90 天不等），不会无限膨胀。

订阅与计费 ​

如果你把框架作为服务对外提供，开箱即用的部分包括：

  • 套餐：月付 / 年付 / 永久等计费模式，套餐里带有机器人位与插件位；
  • 卡密：批量生成、导出、作废，用户自助兑换；
  • 余额与充值：对接易支付，充值后余额可用于购买或续费套餐；
  • 配额校验：超出套餐配额会被拒绝并给出明确提示 —— 新建机器人校验机器人位，安装插件校验插件位。

详见 订阅 · 卡密 · 充值。

开发者友好 ​

  • 在线云编译：把插件源码打包上传，网页上点一下就能编译出可上架的插件包，不用自己搭 C++ 环境。
  • ABI 版本协商：框架加载插件时校验版本兼容性，不兼容会明确告知原因，而不是崩溃。
  • 调试手段：插件日志直接进机器人日志页；能力调用结果原样返回，便于定位是「没权限」还是「参数不对」。
