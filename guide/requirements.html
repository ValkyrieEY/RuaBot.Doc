系统要求 ​

部署前对照这张表检查一遍，绝大多数「装不上」都是这里少了一项。

运行环境 ​

项要求说明
操作系统Ubuntu 24.04 x86_64（amd64）这是官方构建与验证环境。Debian 12 等同代发行版一般可用；CentOS 7 等老系统不建议
CPU1 核起框架本身很轻，插件多、机器人群多时按需加核
内存1 GB 起建议 2 GB 以上，留出数据库与插件运行空间
磁盘2 GB 起消息记录与日志会持续写入，按业务量预留
PostgreSQL12 及以上可以装在同一台机器，也可以是已有的独立实例
网络能访问外网用于连接平台网关、调用外部接口、发邮件等

不需要的东西

不需要 Redis、不需要消息队列、不需要 Node.js、不需要单独部署 Web 服务器（前端已内嵌在程序里）。

数据库 ​

  • 需要一个可用的 PostgreSQL 实例，并准备好连接信息：地址、端口、用户名、密码、库名。
  • 建表和升级由程序启动时自动完成，你不需要手工导入 SQL。
  • 建议为该实例设置定期备份（见 备份与运维）。

系统依赖 ​

如果使用提供的安装包，安装脚本会处理依赖；如果是手动运行二进制，需要确认系统里已有：

bash
# 动态链接版需要的两个运行库
sudo apt-get update
sudo apt-get install -y libpq5 libssl3t64
静态链接版

如果分发的是静态链接版本，则不需要额外安装运行库，可以直接运行。

端口 ​

端口用途是否必须对外开放
8080管理控制台、安装向导、Webhook 回调、开放 API需要（建议经反向代理 + HTTPS）
8081适配器数据面：OneBot 反向 WebSocket 接入仅在用 OneBot 11 时需要
5432PostgreSQL 默认端口数据库不在本机时需要放通

端口冲突

如果 8080 / 8081 已被占用，程序会启动失败并提示地址被占用。可以在配置文件里改成其他端口，改完重启服务。

网络与域名 ​

  • 只用 WebSocket 网关方式接 QQ 官方机器人：不需要公网域名，框架主动连平台。
  • 用 Webhook 回调方式：平台要主动回调你的服务器，必须有公网可访问的地址，并在「平台设置 → 站点」里把协议与域名配好，否则回调地址会退化成内网地址。
  • 用 OneBot 11：实现端要能连上你的 8081 端口，通常是同机部署或同内网。

客户端 ​

角色要求
管理控制台现代浏览器（Chrome / Edge / Safari / Firefox 近两年版本）
QQ 官方机器人相关功能较新版本的 QQ 客户端（按钮、Markdown 等能力依赖客户端支持）

授权文件 ​

程序启动时需要一个由服务商提供的授权文件，放到程序同目录即可。

  • 授权与服务器绑定：换服务器或换机器需要联系服务商重新签发。
  • 授权到期后程序会停止运行，续期后重启即可。
  • 授权文件请妥善保管，不要放进任何公开仓库或分享给他人。
