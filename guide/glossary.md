# 名词解释

阅读文档前，先熟悉这些核心概念。

## 平台与适配器

| 名词 | 含义 |
|------|------|
| **平台** | 即时通讯服务，如 QQ 官方、Telegram、Discord 等 |
| **适配器（Adapter）** | 连接某个平台的桥梁，负责把平台事件转成统一格式、把统一消息发回平台 |
| **连接模式** | 适配器接入平台的方式：Webhook 回调、正向 WebSocket、反向 WebSocket、长轮询等 |

## 机器人与租户

| 名词 | 含义 |
|------|------|
| **机器人（Bot）** | 一个具体的机器人实例，绑定到一个平台账号，归属于某个用户 |
| **租户 / 用户** | 平台上的一个客户，拥有自己的机器人、订阅、余额 |
| **绑定（Binding）** | 机器人与插件的关联关系——一个机器人装了哪些插件、各自的开关与设置 |

## 插件与 XUBP

| 名词 | 含义 |
|------|------|
| **插件（Plugin）** | 提供某项功能的可安装模块，如签到、积分商城、视频解析 |
| **XUBP** | Xiaoyi Universal Bot Protocol，V3 的通用插件开发协议，让插件跨平台通用 |
| **事件（Event）** | 平台发生的事情（收到消息、被加群等），标准化后传给插件 |
| **钩子（Hook）** | 插件里定义的特定函数（如 `handle_event`），框架在对应时机自动调用 |
| **上下文（Context）** | 钩子函数收到的对象，包含事件数据、配置、发送消息的方法等 |
| **data_store** | 插件的数据存储接口，按 `插件 + 用户 + 机器人` 自动隔离 |
| **拦截器** | 一种特殊插件，在消息发出前 / 发出后介入，可修改或阻断消息 |

## 商业化

| 名词 | 含义 |
|------|------|
| **订阅（Subscription）** | 用户购买的服务套餐，决定可用机器人数、插件数等配额 |
| **套餐（Plan）** | 订阅的规格，分月付 / 年付 / 永久 / 自定义 |
| **卡密（Card Key）** | 可兑换套餐、余额或插件的兑换码 |
| **余额** | 用户账户里的预存金额，可购买插件、续订 |
| **开发者分成** | 客户购买付费插件时，开发者获得的收益比例 |

## 权限与角色

| 名词 | 含义 |
|------|------|
| **RBAC** | 基于角色的权限控制 |
| **管理后台** | 平台运营方使用的管理界面 |
| **用户控制台** | 租户使用的自助界面 |
| **开发者中心** | 插件开发者上传、管理插件的界面 |
| **审计日志** | 记录关键操作（谁、何时、做了什么）的日志 |

## 其他

| 名词 | 含义 |
|------|------|
| **Open API** | 对外开放的 HTTP API，凭 API Key 调用，用于二次集成 |
| **WebUI** | 插件自带的管理界面，在机器人配置页内嵌展示 |
| **授权码（authcode）** | 域名绑定授权的凭证，安装时自动获取或手动填写 |
