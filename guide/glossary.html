名词表 ​

文档里出现的术语，按出现频率从高到低排列。看文档时遇到不认识的词，回这页查。

框架与部署 ​

术语含义
框架Xiaoyi_QQ_V4 本体，即那个可执行文件。所有机器人、插件都运行在它里面
控制台框架自带的网页管理界面，默认在 8080 端口
安装向导首次启动时自动进入的初始化页面，用来填数据库信息并创建管理员
管理面 / 数据面管理面是控制台与接口（8080）；数据面是机器人连接的接入端口（8081）
授权文件服务商提供的文件，放在程序同目录，用于启动校验

接入相关 ​

术语含义
适配器连接某一类平台的组件。目前有 QQ 官方与 OneBot 11 两种
QQ 官方机器人在 QQ 开放平台创建的机器人，通过官方接口收发消息
OneBot 11一套被广泛实现的机器人协议，通常由 NapCat、Lagrange、go-cqhttp 等实现端提供
实现端在 OneBot 场景里，真正登录 QQ 并与框架对接的那个程序
反向 WebSocketOneBot 实现端主动连到框架的模式（区别于框架去连实现端）
Webhook平台主动把事件推给你的服务器，需要一个公网可访问的回调地址
回调地址你提供给平台的 URL，格式形如 {协议}://{域名}/api/webhooks/adapters/{适配器}/{机器人UUID}
UUID每台机器人在框架内的唯一标识，回调地址、开放 API 里都会用到
全量消息授权QQ 官方平台的一项设置，授权后机器人才能收到群里没有被 @ 的消息

插件相关 ​

术语含义
插件独立的 .so 文件，装在机器人上运行，为机器人增加功能
插件市场控制台里浏览、安装插件的页面
绑定 / 安装到机器人把插件挂到某台机器人上，只对该机器人生效
插件面板插件自带的网页配置界面，在机器人详情页里打开
ABI插件与框架之间的二进制接口约定，有版本号；版本不匹配的插件会被拒绝加载
SDK一个头文件，写插件时 #include 它就能用框架提供的能力
元数据插件里声明自己名字、版本、分类、图标等信息的那部分
事件框架交给插件的「发生了什么」，例如群消息、成员入群、入群申请、按钮点击
拦截器插件在消息处理链路中插入的钩子，可以改写或阻断消息
事件订阅插件声明自己只关心哪几类事件，其余事件不会被推给它
云编译在线上把插件源码编译成插件包的服务，不用本地配 C++ 环境

能力调用 ​

术语含义
平台能力平台提供的一组操作，例如禁言、踢人、撤回、审批入群
能力码平台能力的统一编号，形如 xubp.group.member.mute。插件用它调用能力，不用关心背后是哪个平台
能力探测调用前先问框架「这台机器人支持这个能力吗」，不支持时降级处理
降级平台不支持某项能力时改用别的做法，例如按钮不可用时改发文字指令

账号与商业化 ​

术语含义
用户控制台的使用者，可以拥有多台机器人
管理员能进入平台管理后台的角色，管理用户、套餐、插件上架、平台配置
套餐订阅方案，决定这个账号能拥有多少台机器人、安装多少个插件
机器人位 / 插件位套餐里的配额单位：机器人位限制能建几台机器人，插件位限制能装多少插件；超配额时新建/安装都会被拒绝
卡密一串兑换码，用户自助兑换成套餐或余额
开放 API用 API Key 调用的接口，可以在程序外部查询状态或让机器人发消息
